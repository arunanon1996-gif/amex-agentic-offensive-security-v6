Agent Action Scoring

This page explains the transparent POC prioritization model used to choose the next best security validation. It is an explainable prototype scoring model, not a universal pentest risk standard.

Scoring model

Evidence value30%
Impact30%
Applicability / exploitability25%
Cost penalty-10%
Risk penalty-5%
Score = (Impact × 0.30) + (Evidence × 0.30) + (Applicability × 0.25) − (Cost × 0.10) − (Risk × 0.05)

How the agent uses it

1. Evidence creates candidate hypotheses.

2. Each hypothesis exposes one or more candidate actions.

3. The scorer evaluates each action using confidence/evidence, impact, applicability, cost and risk.

4. The highest-ranked policy-approved action becomes the Next Best Action.

5. Its result becomes new evidence and the cycle repeats.

What you can inspect during a run

Every decision in the dashboard includes the selected score and a breakdown for evidence value, exploitability/applicability, confidence, impact, coverage and risk. This makes the agent's decision trace auditable.
